# Активник Нижний Новгород

Агрегатор студенческих анонсов вузов Нижнего Новгорода.
Читает публичные Telegram-каналы вузов → ИИ-модерация (Groq) → публикация
интересных анонсов в канал [@aktivnik_nn](https://t.me/aktivnik_nn).

## Как работает

1. **Сбор** — читает посты через веб-превью `t.me/s/<канал>` (без бота в канале
   и без юзер-аккаунта; только публичные каналы).
2. **Модерация** — Groq решает, анонс ли это интересного мероприятия, ставит
   оценку интересности; проходной балл 6/10. Скучное/отчёты/бюрократия отсекаются.
3. **Дедуп** — одинаковые афиши (по названию+дате) и кросспостинг не публикуются дважды.
4. **Публикация** — «тупой репост» одним сообщением: текст со ссылками + фото/видео.
5. **Ревью** — афиши-картинки без текста уходят владельцу в ЛС с кнопками ✅/❌.
   Не разобранные за 3 дня — авто-отклоняются.

## Управление (в ЛС бота, только владелец)

- `/menu` — меню с кнопками
- `/add username` — добавить канал (публичный, без @)
- `/del username` — убрать канал
- `/list` — источники
- `/stats` — статистика (всего и по каждому каналу)
- `/review` — переслать посты, ждущие решения
- `/help` — справка

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # заполни BOT_TOKEN, OWNER_ID, GROQ_API_KEY
python main.py
```

## Деплой на Railway

1. Подключить этот GitHub-репозиторий (Deploy from GitHub repo).
2. Задать переменные окружения: `BOT_TOKEN`, `GROQ_API_KEY`, `OWNER_ID`,
   `CHANNEL`, `DATA_DIR=/data`.
3. Добавить Volume, смонтировать в `/data` — чтобы БД и список каналов
   переживали передеплой.

Процесс запускается как `worker` (см. `Procfile`) — HTTP-порт не нужен.
